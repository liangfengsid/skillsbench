# SkillsBench splits (Hermes)

Reproducible **train/test** partitions for `benchmark/skillsbench/tasks/` (88 tasks in this checkout).

SkillsBench upstream does not define splits; these files are generated by [`../scripts/make_skillsbench_splits.py`](../scripts/make_skillsbench_splits.py).

## Bundled splits

| File | Protocol | Counts |
|------|----------|--------|
| `stratified_v1.json` | `difficulty_stratified` (75/25, seed 42) | 65 train / 23 test |
| `category_holdout_v1.json` | `category_holdout` (categories with ≥3 tasks → test) | 64 train / 24 test |

Each JSON includes `stats` with per-split difficulty histograms.

## Regenerate

```bash
python3 benchmark/scripts/make_skillsbench_splits.py --write-defaults
```

## Use with Hermes driver

```bash
python3 benchmark/scripts/run_skillsbench_with_hermes.py --all \
  --split-file benchmark/skillsbench_splits/stratified_v1.json \
  --split-part train
```

`--split-part` is one of `train`, `test`, or `all`.

## Use with CoEvoSkills baseline

```bash
# Evolve on train, then frozen eval on test — see baselines/coevoskills/README.md
python -m benchmark.baselines.coevoskills.run_split_protocol \
  --evolve --split-part train \
  --split-file benchmark/skillsbench_splits/stratified_v1.json

python -m benchmark.baselines.coevoskills.run_split_protocol \
  --build-library --library-source-part train \
  --frozen-eval --split-part test \
  --pass-k 1,5,10,70 --max-iterations 90 \
  --log-jsonl benchmark/runs/coevo_frozen_test.jsonl
```
